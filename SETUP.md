# Setup and submission notes

This is a team project for CS 410 at UIUC. The original short README and Python scripts are preserved. Individual contributions should be documented separately before using this repository as a personal portfolio.

## Run from the extracted CSV

Use Python 3.10 and install dependencies from requirements.txt in an isolated environment. Jupyter is additionally required to use the notebook. The original environment used transformers 4.37.2; the broad version ranges in requirements.txt have not been tested against current releases.

Place the original extracted CSV at data/politifact_extracted.csv, then run from the scripts directory:

```sh
cd scripts
python train_baseline.py
python train_BERT.py
python evaluate.py
python data_analysis.py
python software_deploy.py
```

The baseline script creates the train/dev/test splits and output directories. DistilBERT training downloads a pretrained model and requires additional compute. The desktop interface needs Tkinter and the model artifacts generated by training.

Alternatively, open scripts/run_all.ipynb with scripts as the working directory. Skip the preprocessing cell when using the existing extracted CSV. The preprocessing script retains Windows paths from the original submission; to regenerate the CSV from raw FakeNewsNet JSON, update its input_dir and output_path first. Notebook outputs were cleared in this public-sharing copy to omit local paths and article excerpts.

## Recorded results and limitations

The original notebook records 514 extracted rows, with 352 training, 76 development, and 76 test examples after dropping missing text/title values.

| Model | Test accuracy | Macro-F1 |
| --- | --- | --- |
| TF-IDF + stylometric features + Logistic Regression | 0.8684 | 0.8683 |
| DistilBERT | 0.9342 | 0.9339 |

These values were transcribed from saved notebook output, not reproduced during packaging. A different historical run may produce other results. Do not mix metrics from different runs.

The supplied classifiers use article title/body text and stylometric features; they do not consume a social graph or social engagement features. Preprocessing does not explicitly deduplicate articles. The DistilBERT best-state assignment uses model.state_dict() without a deep copy, so its intended best-development checkpoint selection requires review before treating a rerun as a reliable model comparison. The GUI baseline cleaning also differs from training preprocessing by not removing stopwords.

Original data and trained models are not included. The full training pipeline and desktop app have not been executed during packaging. All Python scripts passed syntax parsing.
